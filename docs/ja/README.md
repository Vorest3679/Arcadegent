## 公開ドキュメントの境界

実際の店舗データ、取得データ、実行 cache、QA/評価レポート、DB export、本番 .env、API key、Supabase service role key、地図サービス key、非公開データ path、一時的な issue 議論、ローカル絶対パスを公開・commit しないでください。

データ経路は「JSONL 互換データソース」「非公開データディレクトリ」「DB read model」のように一般化して説明します。個別のファイル名、バッチ出力、import script はローカル文書に残します。
